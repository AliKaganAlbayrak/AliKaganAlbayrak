# Ali Kağan Albayrak

Software developer focused on machine learning, LLMs and turning models into products people can use.

My work usually sits between data, models and the apps around them. I like taking a rough idea all the way to a working system, keeping sensitive data on the machine, and making a model explain its answers instead of just giving them.

## focus areas

- Python, Java, C, TypeScript, React, FastAPI
- machine learning, anomaly detection and explainable scoring
- privacy-first tools built on local LLMs
- automotive software: embedded C, CAN bus, sensor data and autonomous driving
- full-stack web and desktop apps with auth, PostgreSQL and clean dashboards

## selected work

- [Local LLM Manufacturing Analytics](https://github.com/AliKaganAlbayrak/local-llm-manufacturing-analytics): factory log analytics where SQL computes the metrics, anomaly detection flags unusual runs and a local LLM writes the reports. The original version ran on 500K+ real machine records at a manufacturing company.
- [Smart Wardrobe](https://github.com/AliKaganAlbayrak/smart-wardrobe): multi-user wardrobe app with private collections and explainable outfit recommendations, built with FastAPI, React and Supabase
- [Contract Risk Analyzer](https://github.com/AliKaganAlbayrak/sozlesme-risk-analizoru): desktop app that reviews PDF contracts with an LLM, flags risky clauses and gives a 0–100 risk score
